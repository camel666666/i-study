# Study Focus Workstation / 学习监督台

面向大学生的本地专注工作台，也是本仓库的第一个 job。它通过浏览器中的目标识别模型辅助判断在座状态、疑似手机和电脑画面，并提供番茄钟、任务安排、分级提醒和温和的补偿专注措施。

## 功能

- 考研、课程复习、项目开发、论文写作四种任务模板
- 电脑模式和手部 / 桌面模式
- 当前学习画面校准与误判处理
- 教练式、挑战式、安静式三种提醒风格
- 本地目标识别、语音提醒、任务清单和本轮记录
- 纠偏采用补偿专注与重启挑战，不采用伤害、羞辱或金钱处罚

## 启动

在此目录运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`，选择场景和摄像头模式，点击“开始监督”并允许摄像头权限。画面稳定后可以点击“以当前画面校准”。

## 隐私与限制

- 摄像头帧仅在浏览器本地处理，不保存照片或视频，也不上传。
- 本地仅保存任务清单，不保存摄像头识别结果。
- 目标识别只能给出“人”“疑似手机”“电脑”等视觉线索，不能判断电脑上具体运行的内容，也不能判断是否真正学会了。
- 光线、遮挡、摄像头角度会造成误判，界面提供了“这是误判”按钮。
- 使用学习结果自检，例如做题、闭卷回忆或提交一个可运行的小成果，才能确认学习质量。
