# i-study

**Local-first focus supervision for study and deep work.**

面向大学生的本地专注工作台：安排任务、观察分心线索、及时纠偏，并用可检查的学习结果完成闭环。

> [!IMPORTANT]
> i-study 是辅助工具，不是行为裁判。摄像头只能提供“疑似手机、在座状态、桌面变化、电脑进入画面”等视觉线索，不能判断电脑中运行的内容，也不能证明用户真正学会了知识。

## 为什么做 i-study

传统计时器只记录时间，却不知道这一小时是否被手机、离席或无目的浏览打断。i-study 把一轮专注拆成四个可以执行的环节：

1. 选择学习或工作场景，生成具体任务。
2. 使用摄像头在本地识别可能的分心线索。
3. 通过不同强度和风格的提醒及时回到任务。
4. 用做题、闭卷回忆或可运行成果验证学习质量。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 场景任务 | 内置考研、课程复习、项目开发、论文写作模板 |
| 计划导入 | 支持 `.txt`、`.md`、`.csv`、`.json`，按任务时长依次执行 |
| 双画面模式 | 电脑模式关注在座与手机；手部 / 桌面模式不依赖完整人体画面 |
| 本地视觉识别 | 识别人、疑似手机、书本、电脑，并记录画面变化线索 |
| 学习基准 | 连续采样当前学习画面，容忍写字、翻页和轻微姿势变化 |
| 分级纠偏 | 教练式、挑战式、晓艳式、安静式提醒，可选择本地 GIF |
| 衡水模式 | 2 秒手机阈值、10 秒离席阈值和 2 / 5 / 10 分钟逐级补偿 |
| 误判处理 | 可以标记误判；离席误判后，本轮仍继续监督疑似手机 |

## 快速开始

要求：现代 Chromium 浏览器、Python 3 和可用摄像头。项目没有后端，不需要账号。

```bash
git clone <repository-url>
cd i-study
python3 -m http.server 4173
```

打开 [http://localhost:4173](http://localhost:4173)，允许当前本地页面使用摄像头。

### 推荐使用流程

1. 选择考研、课程、项目或论文场景，也可以导入自己的计划。
2. 根据构图选择“电脑模式”或“手部 / 桌面模式”。
3. 选择提醒强度与提醒风格，点击“开始监督”。
4. 画面稳定后点击“以当前画面校准”。
5. 每轮结束后用做题、复述或可交付成果进行自检。

## 导入学习计划

Markdown、文本和 CSV 可以使用下面的格式：

```text
- 阅读项目需求 | 20
- 完成核心功能 | 45
- 测试并记录问题 | 15
```

JSON 支持任务数组，字段可以使用 `title` 和 `minutes`：

```json
[
  { "title": "完成一组真题", "minutes": 45 },
  { "title": "闭卷回忆核心方法", "minutes": 15 },
  { "title": "整理错题原因", "minutes": 20 }
]
```

成功导入后，第一项任务的时长会成为当前专注时长；完成任务后进入休息，再继续下一项。

## 摄像头模式

### 电脑模式

适合摄像头能看到上半身和电脑的场景。系统关注是否在座、是否出现疑似手机，以及电脑是否进入画面。它无法区分电脑上的学习、编程、游戏或社交媒体。

### 手部 / 桌面模式

适合只拍到手、书本和桌面的构图。系统不会因为看不到脸或完整身体而判定离席，主要依据疑似手机、桌面活动与已校准画面的变化进行提示。

## 提醒策略

- **教练式**：给出一个可以立刻执行的下一步。
- **挑战式**：用 60 秒重启挑战恢复节奏。
- **晓艳式**：使用原创幽默鼓励文案；不是官方内容，不收录未经授权的真人素材或原话。
- **安静式**：只显示视觉提示，不主动朗读。
- **衡水模式**：提高识别与补偿强度，但不会使用伤害身体、剥夺睡眠、羞辱或金钱处罚。

设置页提供外部 GIF 候选链接。自定义图片只生成当前页面使用的本地临时地址，刷新后失效，不会提交到服务器。

## 隐私模型

- 摄像头帧只在当前浏览器中处理，不保存照片或视频。
- 项目没有后端、遥测、登录系统或云端数据库。
- 任务清单保存在浏览器 `localStorage` 中。
- 动作记录只保存在当前页面内存中，刷新后清除。
- 只有主动点击外部推荐素材时，浏览器才会访问第三方网站。

## 已知限制

- 遮挡、逆光、低照度和狭窄构图都会影响手机与人体识别。
- “书写、翻页、姿势调整”等动作来自画面变化推测，不是行为事实。
- 普通摄像头无法识别电脑屏幕内容，也无法判断是否真正理解知识。
- GIF、语音合成和摄像头权限的具体表现取决于浏览器。
- 当前版本是原型，识别结果不应用于纪律处分、成绩评价或其他高影响决定。

## 技术结构

```text
浏览器摄像头
    |
    +-- MediaPipe EfficientDet -> 人 / 手机 / 书本 / 电脑线索
    +-- 低分辨率画面采样 -> 学习基准与动作变化
    +-- 本地状态机 -> 计时、任务、提醒、日志
    `-- localStorage -> 仅保存任务清单
```

项目使用原生 HTML、CSS 和 JavaScript。MediaPipe 运行时与模型已包含在 `vendor/` 中，页面运行时不需要从 CDN 下载模型。
