# i-study

`i-study` 是面向大学生的本地专注工作台，也是本仓库的第一个 job。它通过浏览器中的目标识别模型辅助判断在座状态、疑似手机和电脑画面，并提供番茄钟、任务安排、分级提醒和温和的补偿专注措施。

## 功能

- 考研、课程复习、项目开发、论文写作四种任务模板
- 电脑模式和手部 / 桌面模式
- 当前学习画面校准与误判处理
- 教练式、挑战式、晓燕式、安静式四种提醒分支，以及可选的本地 GIF
- 衡水模式：更短提醒阈值、挑战式语音和逐级补偿专注
- 一键导入 `.txt`、`.md`、`.csv`、`.json` 学习计划，按任务时长依次执行
- 本地目标识别、语音提醒、任务清单和小动作记录
- 纠偏采用补偿专注与重启挑战，不采用伤害、羞辱或金钱处罚

## 启动

在此目录运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`，选择场景和摄像头模式，点击“开始监督”并允许摄像头权限。画面稳定后可以点击“以当前画面校准”。

计划文件可以逐行写成 `任务名称 | 分钟数`，CSV 可以使用 `任务名称,分钟数`，JSON 支持任务数组或包含 `tasks` 数组的对象。

## 隐私与限制

- 摄像头帧仅在浏览器本地处理，不保存照片或视频，也不上传。
- 本地仅保存任务清单，不保存摄像头识别结果。
- 小动作记录是基于画面变化的推测，例如疑似书写、翻页或调整姿势，并不是行为事实。
- 自定义 GIF 只生成当前页面使用的本地临时地址，刷新后失效。
- 目标识别只能给出“人”“疑似手机”“电脑”等视觉线索，不能判断电脑上具体运行的内容，也不能判断是否真正学会了。
- 光线、遮挡、摄像头角度会造成误判，界面提供了“这是误判”按钮。
- 使用学习结果自检，例如做题、闭卷回忆或提交一个可运行的小成果，才能确认学习质量。
