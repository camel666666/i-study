# 学习监督台

一个只在本机处理摄像头画面的学习监督网页。它通过浏览器中的目标识别模型检测是否在座、画面中是否出现手机，并提供番茄钟、任务安排、分级提醒和温和的补偿专注措施。

## 启动

在此目录运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`，点击“开始监督”并允许摄像头权限。

## 隐私与限制

- 摄像头帧仅在浏览器本地处理，不保存照片或视频，也不上传。
- 本地仅保存任务清单，不保存摄像头识别结果。
- 目标识别只能判断画面中是否有“人”或“疑似手机”，不能判断是否真正学会了。
- 光线、遮挡、摄像头角度会造成误判，界面提供了“这是误判”按钮。
